智能门禁系统
技术栈：C/C++、STM32F103C8T6、Keil、STM32标准外设库、MicroPython、ESP32-CAM、
Python、OpenCV/LBPH、UDP、USART/I2C/SPI/PWM、RC522、AS608、OLED、HC-05、
嘉立创EDA、Gerber、DRC、硬件调试

项目描述：面向STM32F103C8T6与ESP32-CAM设计的五模态智能门锁系统，集成人脸识别、
RFID刷卡、AS608指纹、矩阵密码和HC-05蓝牙控制。ESP32-CAM负责图像采集并通过WiFi
将JPEG图像传输至PC，PC端Python完成人脸训练与识别，识别成功后通过USART向STM32
发送开门命令，由STM32控制舵机模拟门锁并完成OLED状态显示和声光提示。

项目职责：

• 负责系统整体架构设计，划分STM32门锁主控、ESP32-CAM图像采集和PC人脸识别三个子系统，
  完成模块资源分配、通信协议、供电方案和软硬件接口定义。

• 基于STM32F103C8T6开发门锁主控固件，完成GPIO、USART、软件I2C、SPI、TIM-PWM等
  底层驱动，集成RC522、AS608、4×4矩阵键盘、OLED、HC-05、SG90舵机和蜂鸣器。

• 实现RFID卡号匹配、指纹录入/删除/校验、矩阵键盘密码验证和蓝牙远程开门等多模态认证
  逻辑，并通过舵机完成模拟门锁开关，配合LED和蜂鸣器实现操作状态提示。

• 设计ESP32-CAM MicroPython固件，实现WiFi自动连接、OV2640图像采集、JPEG压缩、
  UDP图像服务、客户端注册和ESP32 IP自动发现，支持设备上电后自动运行图像服务。

• 开发PC端Python人脸识别程序，基于OpenCV Haar级联分类器完成人脸检测，使用LBPH算法
  完成模型训练与身份识别，解决摄像头图像旋转、中文路径读写、训练模型离线保存等问题。

• 实现电脑与STM32之间的USART通信，人脸识别成功后自动发送“FF AB CD FE”开门命令，
  支持串口端口自动检测，避免ESP32烧录串口与STM32通信串口冲突。

• 完成两层PCB设计，将板框控制在100.0mm×96.52mm以内，完成元件布局、走线、GND铺铜、
  DRC修复及Gerber、BOM、CPL和网表导出，满足低成本打样和手工焊接要求。

• 参与硬件联调和故障定位，使用串口日志、I2C扫描和摄像头初始化测试排查CH340串口占用、
  FPC排线接触、VSYNC同步异常和摄像头供电问题，提升系统稳定性和问题定位效率。
